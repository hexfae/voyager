# Void Codex

Void Codex is a library mainly providing structs, enums, and functions for describing and parsing
[Endless Void](https://github.com/Skirlez/void-stranger-endless-void) levels. It serves as the base
for Void Voyager.

## Features

- A sophisticated level parser
- Comprehensive documentation
